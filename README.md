Welcome to my A-Level computer science coursework. The name of the program is 'Interview Lab'. Designed to support a real life solution - "preparing for a job interview" this programs allows you to run realtime interview simulations, personalised to your job and interview requirements. There is also an automated feedback system that allows you to develop your knowledge to how to improve for your next interview. The program is run on a CustomTkinter GUI so is intuitive and user friendly to use. The interview itself is powered behind Livekit's real time live voice agents.

🌟 Highlights

User log-in system
Input job information such as your CV and the job specification
Customise your interview - what type of questions you want to be asked, what persona your interview will be, time length of interview and difficulty level
Run a interview simulation using LiveKit's realtime live voice agents
Receive useful personalised feedback on your interview simulation within 30secs of finishing the interview
